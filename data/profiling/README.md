# Profiling results

Esta carpeta almacena los reportes generados durante el perfilado estructural de las fuentes oficiales del MEF.

Los reportes podrán incluir:

- cantidad de filas y columnas;
- nombres y orden de columnas;
- tipos de datos preliminares;
- columnas documentadas y no documentadas;
- diferencias de esquema entre periodos;
- cobertura mensual;
- fecha y hora de ejecución.

Los reportes generados no se versionarán en GitHub. Solo este archivo de documentación permanecerá en el repositorio.
