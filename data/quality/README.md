# Data quality results

Esta carpeta almacena los reportes generados durante la evaluación de calidad de las fuentes oficiales del MEF.

Los reportes podrán incluir:

- validación del año de ejecución;
- valores nulos por columna;
- montos negativos;
- reconciliación del Devengado anual contra los meses;
- filas duplicadas;
- evaluación de claves naturales candidatas;
- consistencia entre códigos y descripciones;
- controles críticos, advertencias e indicadores informativos;
- fecha y hora de ejecución.

Los reportes generados no se versionarán en GitHub. Solo este archivo de documentación permanecerá en el repositorio.
