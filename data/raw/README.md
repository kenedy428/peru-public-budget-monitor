# Raw data

Esta carpeta almacena los archivos originales descargados desde las fuentes oficiales del Ministerio de Economía y Finanzas del Perú.

## Reglas de uso

- Los archivos deben conservarse sin modificaciones.
- Cada descarga deberá registrar su URL, timestamp, tamaño y hash SHA-256.
- Las transformaciones se realizarán sobre copias o mediante el pipeline.
- Los datasets originales no se versionarán en GitHub debido a su tamaño.
- Solo este archivo de documentación se mantendrá en el repositorio.

Los archivos pueden reproducirse utilizando las URLs y procedimientos documentados en `docs/data_sources.md`.
